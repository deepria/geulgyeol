이 프로젝트는 [Ductus](https://ductus.sorenblank.com/)를 참고하여 한글 버전을 만든 것입니다.

# 글결 — 나만의 한글 손글꼴

브라우저에서 내 글씨를 쓰고, 설치해서 사용할 수 있는 OTF 글꼴로 내려받는 도구입니다. 원하는 글자를 직접 쓰거나 자음·모음을 모아 한글을 조합할 수 있습니다.

**[글결 사용하기 →](https://geulgyeol.deepria.com/)**

## 어떤 방식으로 시작할까요?

| 탭 | 이런 경우에 사용하세요 |
| --- | --- |
| **직접 쓰기** | 이름, 짧은 문구 등 원하는 글자를 내 손글씨 그대로 만들고 싶을 때 |
| **자소 조합** | 완성된 글자를 하나하나 쓰는 대신, 자소를 모아 많은 한글을 만들고 싶을 때 |

두 탭의 작업은 함께 적용됩니다. **직접 쓴 글자가 있으면 그 모양을 먼저 사용하고, 나머지는 준비된 자소로 조합합니다.** 탭을 바꿔도 작성한 내용은 유지됩니다.

## 1. 직접 쓰기

1. **직접 쓰기** 탭을 선택합니다.
2. 안내된 글자를 쓰기 영역에 마우스·손가락·펜으로 씁니다. 옅은 예시 글자의 크기와 위치를 참고하세요.
3. 잘못 그린 획은 **한 획 취소**, 해당 글자 전체는 **지우기**로 지웁니다.
4. **다음 글자**를 누르거나 아래 **나의 글자들**에서 다른 글자를 선택합니다.
5. 문장 미리보기에서 내 글씨가 반영되는 모습을 확인합니다.

원하는 글자가 목록에 없다면 **글자 추가 +**를 누르고 단어나 문장을 입력하세요. 같은 글자는 한 번만 추가됩니다. 예를 들어 `너의 모든 순간을 응원해`를 입력하면 그 문장에 필요한 글자를 골라 쓸 수 있습니다.

직접 쓰기 목록에는 최대 200개 글자를 추가할 수 있습니다. 숫자·문장부호도 원하는 문장에 넣어 추가할 수 있습니다.

### 펜·브러시 고르기

쓰기 칸 위 **도구 고르기**에서 **기본 펜·가는 펜·연필·붓펜·납작 펜** 중 하나를 선택하세요. 작은 선 미리보기로 모양을 비교할 수 있습니다.

- 선택한 도구는 **새로 쓰는 획부터** 적용됩니다. 이미 쓴 획의 모양은 유지됩니다.
- 기존 획을 바꾸려면 **현재 글자의 획에 적용 ↗**을 누르세요. **도구 적용 취소**로 되돌릴 수 있습니다.
- 직접 쓰기와 자소 조합 모두 같은 도구를 사용할 수 있고, 획별 모양은 작업 파일과 OTF에 함께 저장됩니다.
- **글꼴 조절**에서 전체 획 굵기를 조절할 수 있습니다.

엔진은 상업적 사용이 가능한 MIT 라이선스이며 [브러시 출처·적용 방식](docs/BRUSHES.md)과 [라이선스 고지](public/brush-licenses.txt)를 확인할 수 있습니다.

## 2. 자소 조합 — ‘가·각’부터 시작하기

처음이라면 **자소 조합 → 가·각 빠른 시작 ↗**을 눌러보세요. 표시된 칸의 자소만 쓰고 **다음 자소**로 이동합니다.

| 순서 | 쓸 자소 | 쓰이는 위치 |
| --- | --- | --- |
| 1 | ㄱ | ‘가’의 초성 |
| 2 | ㅏ | ‘가’의 중성 |
| 3 | ㄱ | 받침 있는 ‘각’의 초성 |
| 4 | ㅏ | 받침 있는 ‘각’의 중성 |
| 5 | ㄱ | ‘각’의 받침 |

**1·2번을 쓰면 ‘가’, 5번까지 쓰면 ‘각’도 조합됩니다.** 쓰기 칸 가까이에 있는 **바로 보는 조합 결과**와 문장 미리보기에서 확인할 수 있습니다.

같은 ㄱ이나 ㅏ도 받침 유무와 위치에 따라 모양이 달라지므로, 서로 다른 형태로 따로 준비합니다.

## 3. 조합할 수 있는 글자 늘리기

빠른 시작을 마쳤다면 **전체 자소로** 이동하거나 **초성·중성·받침** 메뉴에서 계속 작성하세요.

1. 작성할 자소 종류를 선택합니다.
2. **자소 형태**에서 받침 유무와 모음 방향에 맞는 형태를 고릅니다.
3. 자소 목록에서 쓸 자소를 선택합니다.
4. 안내된 예시와 표시된 칸을 참고해 **해당 자소만** 씁니다. 완성된 음절 전체를 쓰는 칸이 아닙니다.
5. **모은 자소** 진행률과 조합 가능한 글자 수를 확인합니다.

| 종류 | 준비할 형태 수 |
| --- | ---: |
| 초성 | 76개 |
| 중성 | 42개 |
| 받침 | 54개 |
| **합계** | **172개** |

172개 자소를 모두 준비하면 **현대 한글 11,172자**를 조합할 수 있습니다. 전부 쓰기 전에도 필요한 자소가 갖춰진 글자부터 미리보고 내보낼 수 있습니다.

자소 조합은 입력한 자소를 정해진 배치 규칙에 따라 합치는 방식입니다. 조합이 어색한 글자는 직접 써서 보완할 수 있습니다.

## 4. 어색한 글자를 직접 보완하기

1. 미리보기 문장에 보완하고 싶은 글자를 입력합니다.
2. **문장의 글자 직접 보완 ↗**을 누릅니다.
3. **직접 쓰기** 탭에서 해당 글자를 선택하고 원하는 모양으로 씁니다.

이후 미리보기와 OTF에는 직접 쓴 모양이 우선 적용됩니다. 직접 쓴 획을 모두 지우면, 필요한 자소가 준비되어 있는 경우 조합한 모양으로 돌아갑니다.

## 5. 문장과 글꼴 느낌 조절하기

미리보기의 **어떤 문장으로 볼까요?** 입력란에 원하는 문장을 넣어보세요. 같은 글자는 문장 안에서 반복해서 사용할 수 있습니다.

| 미리보기 표시 | 의미 |
| --- | --- |
| 크림색 | 직접 쓴 글자 |
| 연두색 | 준비된 자소로 조합한 글자 |
| 연한 기본 글꼴 | 아직 직접 쓰거나 조합할 수 없는 글자 |

**글꼴 조절 ↗**에서 획 굵기·글자 크기·글자 간격을 바꿀 수 있습니다. 조절한 값은 미리보기와 다운로드하는 글꼴에 함께 적용됩니다. 원래 설정으로 돌아가려면 **기본값으로**를 누르세요.

미리보기 색상은 글자가 만들어진 방식을 구분하기 위한 표시입니다. 내려받은 글꼴의 색상은 사용하는 앱에서 정할 수 있습니다.

## 6. OTF 글꼴 다운로드하기

1. **글꼴 내보내기 ↗**를 누릅니다.
2. 원하는 **글꼴 이름**을 입력합니다.
3. 포함되는 직접 쓴 글자와 조합 글자 수를 확인합니다.
4. **OTF 글꼴 다운로드 ↓**를 누릅니다. 생성 중에는 진행률을 확인하거나 **생성 취소**를 누를 수 있습니다.
5. 내려받은 `.otf` 파일을 운영체제에 설치하고, 사용하는 앱에서 지정한 글꼴 이름을 선택합니다.

직접 쓴 글자와 필요한 자소가 모두 준비된 조합 글자, 공백이 포함됩니다. 아직 준비되지 않은 글자는 내보내지 않으며, 사용하는 앱에서 기본 글꼴이나 누락 기호로 표시될 수 있습니다.

## 7. 작업 저장·불러오기

작업 내용은 **현재 기기의 현재 브라우저에 자동 저장**됩니다. 다른 기기나 브라우저로 자동 동기화되지는 않으므로, 계속 보관할 작업은 파일로 저장해주세요.

- **작업 저장 ↓**: 다시 편집할 수 있는 `.json` 작업 파일을 내려받습니다. 모바일에서는 화면 아래 **작업 파일로 안전하게 보관하기 ↗** 또는 내보내기 창의 **편집용 작업 파일 저장**을 사용할 수 있습니다.
- **불러오기**: 글결에서 저장한 `.json` 파일을 선택해 직접 쓴 글자·자소·획별 브러시·조절 값·미리보기 문장을 복원합니다. 현재 작업이 있으면 교체 전에 확인합니다.
- 기존 버전에서 저장한 작업 파일도 불러올 수 있습니다.

| 파일 | 용도 |
| --- | --- |
| `.otf` | 다른 앱에 설치해서 사용하는 완성 글꼴 |
| `.json` | 글결에서 불러와 계속 수정하는 작업 파일 |

OTF 파일을 다시 불러와 편집하는 기능은 지원하지 않습니다. **글꼴과 작업 파일을 함께 보관하는 것을 권장합니다.** 손글씨 데이터는 서버로 전송하지 않습니다.

### 전체 작업 초기화

상단 **초기화**를 누르면 삭제할 작업 범위를 확인할 수 있습니다. 보관할 내용이 있다면 확인창에서 **작업 파일 저장 ↓**를 먼저 누른 뒤 **전체 작업 초기화**를 선택하세요.

직접 쓴 글자·모은 자소·도구 선택·글꼴 조절 값·미리보기 문장·글꼴 이름이 처음 상태로 돌아갑니다. 브라우저의 이전 버전 저장본도 함께 정리하므로 새로고침해도 예전 작업이 다시 나타나지 않습니다. 내려받은 JSON·OTF 파일은 삭제하지 않습니다. 초기화를 취소하려면 **계속 작업하기** 또는 닫기를 누르세요.

## 자주 묻는 질문

**자소를 썼는데 글자가 조합되지 않아요.**

그 음절에 필요한 초성·중성·받침과 형태가 모두 준비되어 있는지 확인해주세요. 받침 없는 글자의 자소와 받침 있는 글자의 자소는 별도로 준비합니다. 부족한 자소가 있는 글자는 기본 글꼴로 표시됩니다.

**직접 쓰기 탭으로 바꾸면 자소 조합 작업이 없어지나요?**

유지됩니다. 두 탭은 입력 방법을 바꾸는 메뉴이며, 미리보기와 내보내기에는 두 작업이 함께 적용됩니다.

**폰트를 설치했는데 일부 글자가 다르게 보여요.**

내보낼 때 포함되지 않은 글자인지 확인해주세요. 해당 글자를 직접 추가하거나 필요한 자소를 준비한 뒤 OTF를 다시 내려받으세요.

**브라우저 데이터를 지우거나 기기를 바꿀 예정이에요.**

먼저 JSON 작업 파일을 저장하고, 이후 사용할 브라우저에서 불러오세요.
