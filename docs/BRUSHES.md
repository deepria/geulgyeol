# 브러시 출처와 적용 방식

글결은 [perfect-freehand](https://github.com/steveruizok/perfect-freehand)의 벡터 획 엔진으로 기본 펜·가는 펜·연필·붓펜·납작 펜을 제공합니다. 엔진의 [MIT 라이선스](https://github.com/steveruizok/perfect-freehand/blob/main/LICENSE)는 저작권·허가 고지를 유지하는 조건으로 이용·수정·배포·상업적 사용을 허용합니다. 배포 파일에도 원문 고지를 [포함](../public/brush-licenses.txt)합니다.

조사 과정에서 [Nylnook Krita Brushes](https://github.com/nylnook/nylnook-krita-brushes)의 CC0 브러시 팩도 확인했습니다. 이 팩은 Krita 전용 브러시 자료이며 글결에 해당 팩의 파일이나 이미지를 포함하지 않습니다. 글결의 프리셋은 웹과 일반 OTF에서 함께 사용할 수 있도록 프로젝트 코드로 구성한 벡터 방식입니다.

- **기본 펜**: 기존 획과 동일한 둥근 필압 펜.
- **가는 펜**: 일정한 굵기의 가는 윤곽.
- **연필**: 결정적인 잔결과 작은 벡터 공극을 사용한 질감. 투명도나 이미지 필터에 의존하지 않습니다.
- **붓펜**: 필압 변화와 가늘어지는 시작·끝.
- **납작 펜**: 45도 기울어진 납작한 펜촉으로 방향에 따라 달라지는 굵기.

선택은 새 획부터 적용합니다. 이미 쓴 획은 도구를 바꿔도 유지되며, **현재 글자의 획에 적용**을 누르면 해당 글자/자소만 바뀝니다. **도구 적용 취소**로 직전 변경을 되돌릴 수 있습니다.

작업 파일 version 3에는 각 획의 점·필압·브러시 종류를 함께 기록합니다. version 1·2 작업은 기존 기본 펜으로 변환하며 원래 점과 이전 브라우저 저장본을 보존합니다. 자소 배치, 미리보기, OTF 생성에서도 획별 브러시와 연필의 공극 방향을 유지합니다.
