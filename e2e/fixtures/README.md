`base.ttf` is an original, public-domain test font generated by `make-base.py`.
It contains quadratic outlines, a shared glyph for 나/낙, a zero-width mark,
non-1000 units per em, proportional widths, GPOS kerning, and a GSUB ligature.
No external font assets are bundled. Running the tests does not need Python;
regenerating the fixture needs fontTools.
